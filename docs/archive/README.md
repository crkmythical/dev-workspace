# Archive

Historical records, kept for provenance — not active specs and not read by the build.

- `specs/` — the spec-driven-development docs (requirements / design / tasks) for features as they
  were built: `secure-dev-workspace` (the original workspace), `remote-desktop`,
  `selkies-desktop-migration`, `kasmvnc-framebuffer-fix`, `realtime-backup-s3`, `self-destruct`.
  They describe how things were designed at the time; the current architecture lives in
  `docs/architecture.md` and `docs/rust-migration.md`. Moved here from `.kiro/specs/` on
  2026-10-31 so they stop cluttering the active tree.
